# 🎯 Job Application Tracker

A simple and modern web app to keep track of your job applications — what you’ve applied for, where, and how far you are in the process.

## ✨ Features
- Add, edit, and delete job applications
- Track application status and notes
- Responsive, clean, and minimal UI
- Saves data locally (localStorage)
- Built with reusable React components

## 🛠️ Built With
- **React**
- **TailwindCSS**
- **Vite**
- **LocalStorage**

## 💡 What I Learned
- Managing state and props in React
- Structuring and styling with Tailwind
- Handling forms and user input
- Storing and retrieving data with localStorage
